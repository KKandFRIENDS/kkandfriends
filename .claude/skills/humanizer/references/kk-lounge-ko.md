# 휴머나이저 — kkandfriends 한국어 적용 (라운지 · 블로그)

> 상위 `SKILL.md`는 영어 산문을 전제로 쓰였다. 이 파일은 그 26개 패턴을 KK의 한국어 글에
> 맞춰 좁힌 것이다. **한국어 글에는 이 파일을 적용한다.**

## 한 줄 요약

**26개 중 하나만 중요하다.** `posts/` 34편 전수 측정(2026-10-03) 결과:

| 휴머나이저 패턴 | 한국어 등가 | 측정 |
|---|---|---|
| **§1 Not X but Y** | `아니라` · `아니다` · `아니었다` | **273회 · 편당 8.0** |
| §13 의미 부풀리기 | 변곡점 · 분기점 · 시대의 | 11회 · 편당 0.3 |
| §3 심오한 척 | 본질적으로 · ~의 언어 · 핵심은 | 8회 · 편당 0.2 |
| §15 -ing 장식 | 보여준다 · 드러낸다 · 시사한다 | 5회 · 편당 0.1 |
| §16 광고 문체 | 전례 없는 · 압도적 · 획기적 | 4회 · 편당 0.1 |
| §2 한 줄 마무리(설교형) | 기억해 두자 · 다시 읽어보라 | 3회 · 편당 0.1 |
| §18 is 회피 | 역할을 한다 · 로 작동한다 | **0회** |

KK의 문체는 이미 광고 문체·의미 부풀리기·장식형 서술을 피한다. 남은 구멍이 §1 하나다.
26개를 순서대로 훑는 것은 시간 낭비다. **§1에 집중하고 나머지는 눈으로만 훑는다.**

## §1 — 부정-대조 구문 (주력)

### 한도

본문 전체에서 `아니라` + `아니다` + `아니었다` **합계 2회**. 라운지 초안(700~1,000자)이면 **1회**.

### 치환 수법, 효과 순서대로

**1. 문장 두 개로 쪼갠다 (가장 좋다)**
대비는 남고 구문은 사라진다. 뜻은 오히려 세진다.

- ✗ 이건 지능의 실패가 아니라 배송의 실패다.
- ○ 모델은 답을 만들었다. 보내지 않았을 뿐이다.

**2. 부정 절을 그냥 버린다**
부정 절이 아무도 안 한 주장을 지어내 긍정 절을 커 보이게 만들 때가 대부분이다.

- ✗ 무너진 건 기술이 아니라 대기줄이었다.
- ○ 무너진 건 대기줄이었다.

**3. 긍정형 비교로 바꾼다**

- ✗ 진짜 뉴스는 침묵이 아니라 그 아래 깔린 설계다.
- ○ 침묵보다 그 아래 설계가 중요하다.

### 남겨도 되는 경우

부정 절이 **독자가 실제로 가진 오해**를 교정할 때, 또는 양쪽 절이 각자 정보를 나를 때.
한 편에 한 번은 그런 자리가 있다. 그 한 번에 쓴다.

- ○ 토큰증권은 새로운 증권이 아니라, 같은 증권을 다른 장부에 옮겨 적는 일이다.
  ← 독자 다수가 "새 상품"으로 오해하므로 부정 절이 일한다.

### 문단 단위로도 센다

상위 §1이 지적하듯, 두 문장에 걸쳐 쪼개 놓은 대비도 같은 구문이다.
"이것은 X를 뜻하지 않는다. Y를 뜻한다." — 한 줄짜리와 똑같이 센다.

## 적용하지 않는 것 — KK 하우스 컨벤션

아래는 의도된 규약이다. 휴머나이저를 핑계로 지우지 말 것.

| 상위 규칙 | 처리 | 근거 |
|---|---|---|
| §8 대시(—) 금지 | **무시한다. 대시 유지** | 상위 §Voice가 "글쓴이 샘플이 §8을 덮는다"고 명시한다. `posts/` 34편이 그 샘플이고, 대시는 KK 호흡의 일부다 |
| §20 화살표(→) 장식 | **무시한다. → 불릿 유지** | 하우스 불릿 양식. 라운지 렌더러가 줄바꿈으로 처리한다 (`js/markdown.js`) |
| §20 이모지 | 💡 **최대 1회.** 0회도 괜찮다 | 티저 라인 1회는 블로그 규약. 라운지는 생략 가능 |
| §19 굵게 | **핵심 키워드만.** 라벨 붙은 목록은 금지 | KK 규칙과 이미 같은 방향 |
| §23 지식 한계 고지 | **"확인 필요" 표시는 유지한다** | CLAUDE.md 숫자 규칙이 교차 확인 안 된 값에 이 표시를 **요구**한다. 이건 tell이 아니라 규율이다 |
| §25 문서 자체를 설명하기 | 본문 밖이면 **유지** | 출처 링크·정정 목록은 본문 아래 별도 블록이다. 본문 안에서 글 자체를 설명하는 것만 잡는다 |
| §9 헤징 | 과한 중첩만 잡는다 | 보이스 다이얼이 "결단조, 헤징 없음"이다. 이미 적다 |

## 눈으로만 훑는 것 (측정상 거의 안 걸림)

한 편에서 두 개 이상 동시에 보이면 그때 손본다. 하나뿐이면 둔다.

- **§13** 변곡점 · 분기점 · 시대의 · 서막 · 신호탄 — 평범한 사실에 역사적 무게를 입히는 말
- **§3** 본질적으로 · 결국은 · 핵심은 · `X는 Y의 언어다` 류 잠언
- **§15** 보여준다 · 드러낸다 · 시사한다 — 사실 뒤에 덧붙는 해석 꼬리
- **§16** 전례 없는 · 압도적 · 획기적 · 놀라운
- **§22** 챗봇 잔해 — "물론입니다", "도움이 되셨길", "~해 드릴까요?" (발견 즉시 삭제)
- **§5** 아무도 안 한 반박에 답하기 — "오해 마시길", "그렇다고 ~라는 말은 아니다"

추가로, 2026-09-09 측정에서 나온 KK 고유 버릇 두 개를 같이 본다.

- **`진짜 ~는`** — 34편에 36회. 통찰을 연기하는 장치다. 1회 이하.
- **`발작` 계열 병리 은유** — 발작 · 경련 · 마비 · 출혈 · 심정지. 한 달에 한 번 이하.

## 실행 순서 (라운지 초안)

1. `kk-writing-engine`으로 초안을 쓴다.
2. **이 파일로 교정 패스를 돌린다.** 생성과 교정을 분리한다 — 쓰면서 동시에 피하려 하면 둘 다 흐려진다.
3. 아래를 세고, 넘으면 고친다.

```bash
grep -o '아니라\|아니다\|아니었다' draft.md | wc -l   # 라운지 1, 블로그 2
grep -o '진짜 ' draft.md | wc -l                      # 1 이하
grep -c '발작\|경련\|마비' draft.md                    # 0 권장
```

4. 소리 내어 한 번 읽는다. 상위 §39가 말하듯, 남은 어색함은 문장을 깁는 대신 **문단을 다시 쓴다.**
5. 고친 뒤 사실·숫자·출처가 하나도 빠지지 않았는지 확인한다. 교정 패스에서 수치가 날아가는 일이 가장 흔하다.

## 하지 말 것

- 패턴에 걸렸다고 **사실·숫자·날짜·출처를 지우지 않는다.** 표현만 바꾼다.
- 26개를 기계적으로 전부 적용하지 않는다. 측정상 걸리지도 않는 패턴을 찾아 헤매면
  멀쩡한 문장을 망친다.
- **KK다움을 깎지 않는다.** 구체적인 디테일, 모르는 것 인정, 곁가지, 자기 정정,
  해소되지 않은 양가감정 — 상위 §387이 명시적으로 지키라고 한 것들이고, KK 글에서는 특히 그렇다.
  이 패스의 목표는 중립적인 글이 아니라 **사람이 쓴 것 같은 KK의 글**이다.
